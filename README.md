# Porto Medical: Medical Website (HTML, CSS and Sass)

> **Training project.** This repository was built as part of the *Frontend and Mobile Cross-Platform Training* at the **Information Technology Institute (ITI), Port Said** (03/2025 – 08/2025). It is a learning exercise from the program, not a production application.

A static website for a medical clinic, built with **HTML** and **Sass**.


## Getting Started

```bash
git clone https://github.com/rashaaad19/Porto-Medical.git
cd Porto-Medical
```

Compile the Sass files in `sass/` to CSS (for example with the Sass CLI or the *Live Sass Compiler* extension in VS Code), then open `index.html` in a browser.
